# Kestrel UI 规范

适用范围：启动器（`src/launcher/`）、设置页（`src/settings/`）、共享控件（`src/shared/theme.css`、`update.css`）。
所有值以 `theme.css` 的 token 为准；新增样式优先引用 token，不再写裸数值。

## 1. 画布

| 窗口 | 尺寸 | 约束 |
| --- | --- | --- |
| 启动器 | 780 × 540，最小 520 × 320 | 可调整；设计基准 780 × 540 |
| 设置 | 1040 × 720 | 固定不可调整，小屏按工作区 `avail - 24` 钳制 |

改界面前先按真实画布渲染，不要用更窄的图猜比例。

## 2. 字体

字体族：`var(--font)`（Segoe UI Variable → Segoe UI → 苹方/微软雅黑）。

### 字号（六档 + 一个数值例外）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--fs-caption` | 11px | 徽标、键帽、路径、元信息 |
| `--fs-sm` | 12px | 说明文字、次要信息、列表副标题 |
| `--fs-body` | 13px | 正文、行标题、按钮、分组标题 |
| `--fs-title` | 15px | 空状态标题、紧凑模式搜索框 |
| `--fs-search` | 17px | 启动器搜索框 |
| `--fs-display` | 22px | 设置页 h1、关于页名称 |
| `--fs-calc` | 30px | 仅计算器结果数值 |

不再使用 10 / 10.5 / 11.5 / 12.5 / 13.5 / 14.5 / 15.5 / 20px 这类中间档。

### 字重（三档）

`400` 常规 · `500` 中等 · `600` 半粗。不再使用 450 / 550 / 650 / 700。

### 行高（三档）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--lh-tight` | 1.25 | 单行标题、搜索框 |
| `--lh-normal` | 1.45 | 行说明、表单标签 |
| `--lh-relaxed` | 1.55 | 多行正文、空状态说明 |

## 3. 间距

4px 栅格：`--sp-1` 4 · `--sp-2` 8 · `--sp-3` 12 · `--sp-4` 16 · `--sp-5` 24 · `--sp-6` 32。
1px / 2px 只用于描边；6px 仅用于紧凑控件里图标与文字的间距。

组件尺寸不套栅格，按可点击性单独定义：

| 组件 | 尺寸 |
| --- | --- |
| 启动器结果行 | 46px（紧凑模式 38px） |
| 设置页设置行 | 最小 52px，内边距 12 × 16 |
| 按钮 | 32px / 小号 26px |
| 开关 | 40 × 24 |
| 图标按钮 | 30 × 30 |
| 卡片圆角 | 12px（窗口 18px，控件 8px） |

## 4. 颜色

- **结构中性**：卡片底 `--surface`，描边 `--line`，徽标/键帽/收藏卡 `--chip`，悬浮 `--chip-hover`。
  这些都从 `--text` 派生，换配色方案时不会把边框、页脚、徽标染成不同色相。
- **色相只出现在两处**：`--accent`（强调、选中图标、链接）与 `--hover/--active`（交互态）。
- **不使用**：深色侧栏/标题栏、大面积品牌色、装饰性水印、`--rail*` 一类新 token。
- **只用同色系**：配色方案共 15 套单色相 + 1 套「跟随主题」。旧的多色系方案
  （港湾/极光/林间）已移除，用户配置按 accent 自动迁到最接近的单色相方案；
  新方案之间色相错开至少约 14°，不重复。结构件始终中性，同屏只有一个色相。

### 配色方案的顺序

设置页按 `MONO_SCHEMES` 数组顺序渲染，**数组就是选择器**，所以顺序属于规范：

1. 「跟随主题」固定第一（它是默认值，不属于任何色相）。
2. 其后按 **OKLCH 色相角顺时针**排列，从应用主色蓝（雾蓝 265°）起：雾蓝 → 靛紫 →
   藤紫 → 玫紫 → 樱粉 → 玫瑰 → 赤陶 → 暖砂 → 秋香 → 青柠 → 薄荷 → 青瓷 → 松石 → 天青。
3. 「石墨」无色相，固定排最后。

新增方案必须按色相插到对应位置，`test:palettes` 会断言这个走位是单调的。

### 可读性下限

每个方案在明暗两态都必须满足下表，且是**在所有可能背景上**成立，不只看窗口底色：

| Token | 用途 | 下限 |
| --- | --- | --- |
| `--text` | 正文 | 12:1 |
| `--text-2` | 次要正文 | 5.5:1 |
| `--text-3` | 11–12px 辅助文字 | 4.5:1（WCAG AA 小字） |
| `--accent-text` | 强调色当文字（选中标签、命中高亮、徽标） | 4.5:1 |
| `--accent-ink` | 强调色上的按钮文字 | 4.5:1 |
| `--accent` | 强调色当填充/指示器 | 3:1 |
| `--border` | 描边 | 1.25:1 |

测量背景集：`--bg`、`--surface`、`--surface-2`、`--surface-3`、`--bg-sunken`、
`--hover`、`--active`、`--kbd-bg`，以及强调色淡底（`--accent-soft` 叠加在窗口底色上）。
后四项是「选中行/键帽/徽标」的真实阅读位置，早期只测前三个背景，导致 11px 辅助文字
在选中行上只有 3.85:1。

- **`--accent` 与 `--accent-text` 必须分开**：填充色保留饱和度（3:1 够用），文字色
  沿明度轴推到 4.5:1，色相不变。亮色下有 13/16 套方案的强调色当文字时只有 3.05–4.49，
  直接拿 `--accent` 写 11px 标签是不达标的。
- **「跟随主题」也要检查**：它的色值手写在 `theme.css`，不走生成管线，
  必须与 `THEME_SWATCHES`（设置页预览）保持同一数值；`test:palettes` 会逐 token 比对，
  防止只改一处。

## 5. 启动器布局规则

- 空搜索：收藏夹固定为**一行横向卡片条**（高约 80px，可横向滚动），下方是最近/常用与命令列表。
  收藏不进入键盘列表；键盘 ↑/↓ 只作用于下方列表。
- 搜索结果顺序：**已安装应用 → 收藏 → 用过的 → 其它**；组内按匹配分排序。
- 列表行高必须与 `rowH` 一致，选中底色块用 `translateY(selected * rowH)` 定位。

- 设置页主布局间距归位：分组 30→32、分组标题下 10→8、设置行 13×15→12×16、页脚说明 22→24。

- 调色板预览、更新日志等子组件里仍有 1–2px 级的内边距差异（如 7/9/10px），
  未统一，避免在固定 1040×720 画布上引起整体位移；后续如改这些区域再逐块归位。

并确认旧多色系配置能正确迁移到单色相方案。

## 8. 界面风格层（2026-11-29）

设置里可在 **Fluent 2 / Apple HIG / Material 3 / Ant Design** 四套之间切换，
与亮暗主题、16 套配色**正交**：4 × 2 × 16 = 128 种组合都必须成立。

### 两条铁律

1. **风格只改形状，不碰颜色。** 任何 `[data-style]` 规则里出现新的颜色常量都是 bug；
   颜色只能来自 `--bg / --surface / --text* / --accent*`。这是正交的前提。
2. **字号仍按第 2 节的 6 档走。** 四套只决定行高、控件尺寸、间距与容器形态，
   不新增字号档位（Material 的 10.5px 导航标签是唯一例外，因为图标栏宽 88px）。

### 差异落在哪

| | Fluent 2 | Apple HIG | Material 3 | Ant Design |
| --- | --- | --- | --- | --- |
| 导航 | 240 宽，选中 3px 竖条 + 5% 淡底 | 228 宽无底色，选中灰块 | 88 宽图标栏，选中药丸包图标 | 208 宽菜单，选中浅底 + 强调色字 |
| 分组 | 无卡片，**每行一张** 4px 圆角卡 | 整组一个 12px 容器，行间 0.5px 缩进细线 | 无边框无阴影，靠表面色 6% 提升 | 整组一张卡，标题=卡头，行间 1px |
| 行高 | 54 | 62 | 56 | 44 |
| 开关 | 40×20 | 37×22 | 48×27 描边轨道 | 44×22 |
| 启动器搜索栏 | 通栏 58 + 细线 | 66，19px 输入，无分隔线 | 浮动药丸，无分隔线 | 44 带边框矩形 |
| 启动器行高 | 44 | 52 | 48 | 40 |

### 三个必须记住的实现约束

- **圆角来自风格表**：`theme.ts` 的 `STYLE_RADII` 给每套一组 `[窗口, 卡片, 控件]`，
  `cornerRadius` 滑块（默认 18）变成**倍率**而不是绝对值。不要在样式里另写圆角。
- **行高只有一处**：`Launcher.tsx` 的 `STYLE_ROW_H` 算出 `rowH`，同时以 `--row-h`
  内联写到 `.shell`，因为选中块的位置是 JS 算的。CSS 里不得再写 `--row-h`。
- **QS 搜索栏 ≤ 58px**：窗口高度由 `monitor.rs::compute_qs_geometry` 在页面绘制前算好，
  样式把它撑高就会切掉页脚。`test:styles` 会解析这条上限。

### 已知取舍

- Apple 风格拿不到 SF 字体（授权不允许随应用分发），回退 Segoe UI；骨架成立，字形不是 Apple 的。
- Material 不做动态取色，否则会和现有 16 套配色打架，只借形状与表面分层。
- 暗色下 Apple 的阴影无法表达层级，分组改用比窗口更亮的实底 + 0.5px 细边。
